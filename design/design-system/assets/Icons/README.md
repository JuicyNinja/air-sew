# Icons
Air Sew's hairline set: 1.2px navy (`#18335f`) stroke at 48px, one `needle` red (`#b71c1c`) accent per icon at most — the dashed running stitch on craft icons. Use at 24px minimum, 32px in cards, 48px as feature icons, always beside a label, on light grounds. Full rules in the brand book under Iconography.
