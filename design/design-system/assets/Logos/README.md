# Logos
The Air Sew script wordmark with the red needle, full color (navy `#18335f` lettering, needle `#b71c1c`) on a transparent ground. Use on `surface`, `paper` or `sky` only, at 32px tall or more (40px in the header). A one-color white version for dark grounds is still to be made from the vector source; until then, keep the logo off navy and photos.
